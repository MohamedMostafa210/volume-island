# Install NumberKeys (keyboard with a number row)

## Get the file
1. Open https://github.com/MohamedMostafa210/volume-island/actions
2. Click the newest **Build Keyboard IPA** run with a green check.
3. Scroll to the bottom → **Artifacts** → **NumberKeys-ipa**. Unzip it to get `NumberKeys.ipa`.

## Install
1. Plug the iPhone into the PC, open Sideloadly, drag in `NumberKeys.ipa`, enter your Apple ID, click Start.
2. If asked, turn on Developer Mode: Settings → Privacy & Security → Developer Mode.
3. Trust the app: Settings → General → VPN & Device Management → your Apple ID → Trust.

## Turn the keyboard on
1. Settings → General → Keyboard → Keyboards → Add New Keyboard → NumberKeys → English.
2. Repeat and add NumberKeys → Arabic.
3. Tap each NumberKeys keyboard → turn on **Allow Full Access** (for clicks and haptics).
4. Optional: remove Apple's English and Arabic keyboards so the globe only switches between these two.

Re-install with Sideloadly every 7 days.
